# Raghadooo — Birthday Website

## Files
- `index.html` — page structure and content
- `style.css` — design, responsive layout, animations
- `script.js` — scroll reveals, particles, and YouTube music controls
- `images/photo1.jpg` — the original photo supplied for this project

## Adding the rest of the photos
Place your additional original photos inside:
`images/`

Then duplicate a gallery card in `index.html` and change only the `src`, for example:
`images/photo2.jpg`

The website does not apply image filters, retouching, cropping, or image-generation to the supplied photos.

## Music
The music button controls the YouTube embed for:
https://youtu.be/PqmwUxmRCng?si=bNCbMk4Tuw8E49IA

Because browsers restrict autoplay, the song is started only after the visitor clicks the button.

## Run
Open `index.html` in a browser, or serve the folder with any simple local/static web server.
